# pyACCSharedMemory
Python library for accessing Assetto Corsa Competizione's Shared Memory Interface & Broadcasting Network Protocol (UDP).

## Acknowledgement
This library is based on:
- ACC Shared Memory Documentation from: https://www.assettocorsa.net/forum/index.php?threads/acc-shared-memory-documentation.59965/
- ACC Broadcasting SDK, found in game's `sdk\broadcasting` folder.
- pyLMUSharedMemory: https://github.com/TinyPedal/pyLMUSharedMemory
